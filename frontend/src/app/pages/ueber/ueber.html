Über das Projekt

Dieser Tarifrechner ist ein Demo-Projekt für eine Bewerbung als Full-Stack-Entwickler. Die Firma „Musterversicherung“, alle Fahrzeuge und alle Preise sind erfunden.

Was das Projekt zeigt

  • Microservices: Zwei Java-Dienste, die über REST miteinander sprechen.
  • Robuste Kommunikation: Timeouts und klare Fehlermeldungen, wenn ein Dienst ausfällt.
  • Container und OpenShift: Jeder Teil läuft in einem eigenen Container.
  • Tests: Unit-Tests, Controller-Tests, Integrationstests und End-to-End-Tests.
  • Barrierefreiheit: Bedienbar mit Tastatur und Screenreader (WCAG 2.1 AA).

Architektur

Verwendete Technik

Backend

Frontend
Angular (Standalone Components, Signals, Reactive Forms), SCSS ohne UI-Bibliothek
Tests
JUnit 5, AssertJ, Mockito, MockMvc, Vitest, Playwright, axe-core

Docker, docker compose, OpenShift / Kubernetes, GitHub Actions
