# Frontend (Angular)

Siehe das [Haupt-README](../README.md).

| Befehl | Was er macht |
|---|---|
| `npm start` | Dev-Server auf http://localhost:4200 mit Proxy zu den Backends (`proxy.conf.json`) |
| `npm run build` | Produktions-Build nach `dist/frontend/browser` |
| `npm run lint` | ESLint inkl. Barrierefreiheits-Regeln für Templates |
| `npm test` | Unit-Tests mit Vitest |
